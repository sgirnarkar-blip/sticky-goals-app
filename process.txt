#The 3 Parts of your Website

1.The Frontend (The House): What people see, the colors, the buttons, and where they type their tasks.

2.The Backend (The Delivery Man): When you click "Save," the Backend takes that task and carries it to the basement.

3.The Database (The Basement): A big storage room where the tasks sit in boxes so they don't get lost when you turn off the lights.

Step 1: Prepare your computer

Before you can build, you need "power tools."

Download and install Node.js. (This is the engine that lets your computer run website code).

Download and install VS Code. (This is just a fancy notepad where you will write your code).

Step 2: Create your project folders
Think of this as setting up your workspace.

Create a folder on your Desktop called MyProject.

Inside MyProject, create two more folders: one called frontend and one called backend.

Step 3: Start the Backend (The "Brain")
We start here because the "Brain" needs to exist before the "Face" (Frontend) can talk to it.

Open VS Code.

Go to File > Open Folder and pick your backend folder.

At the top of VS Code, click Terminal > New Terminal. A small black window will open at the bottom.

Type this exactly and hit Enter: npm init -y (This just tells the computer: "Hey, I'm starting a new project here.")

Type this exactly and hit Enter: npm install express (This downloads a tool called "Express" that makes building the brain much easier.)

Step 4: Write your first line of logic
In VS Code, create a new file inside the backend folder and name it index.js.

Paste this simple code in there:

JavaScript
***************************************************************************
const express = require('express'); // Import the tool
const app = express(); // Start the tool

// When someone visits the website, say Hello
app.get('/', (req, res) => {
  res.send('The Brain is Working!');
});

// Start the server on port 5000
app.listen(5000, () => {
  console.log('Server is running on http://localhost:5000');
});
In that black terminal window at the bottom, type: node index.js

***************************************************************************
How to check if it worked:

Open your internet browser (Chrome or Safari) and type http://localhost:5000 in the address bar.

If the screen says "The Brain is Working!", you just built your first Backend.

If it says "Error," something went wrong in the steps above.

## 🛠️ Project Phase 1: The Backend (The Brain)

### 1. Project Setup

* **Folder Creation:** Created a main folder (`my project`) and sub-folders (`backend`, `frontend`).
* **Initialization:** Inside the `backend` folder, you ran `npm init -y`. This created the **`package.json`** file (the project's "Identity Card").
* **Fixing Permissions:** (Windows only) You ran `Set-ExecutionPolicy` in PowerShell to allow your computer to run Node.js scripts.

### 2. Installing the Tools

You installed two essential "packages" into your backend:

* **Express:** The tool that turns your code into a web server.
* **Mongoose:** The tool that allows your server to talk to the MongoDB database.
* *Command used:* `npm install express mongoose`

### 3. Setting up the "Memory" (MongoDB Atlas)

* **Cloud Account:** Created a free account on MongoDB Atlas.
* **Cluster:** Created a shared cluster (AWS / Free Tier).
* **Security:** * Created a **Database User** (username/password).
* **Network Access:** Whitelisted your IP address (set to `0.0.0.0/0`) so the database allows your computer to connect.


* **Connection String:** Copied the `mongodb+srv://...` link to use in the code.

### 4. Writing the "Brain" Code (`index.js`)

You wrote code that does three main things:

1. **Starts the Server:** Listens for visitors on Port 5000.
2. **Connects to Memory:** Uses your MongoDB link (replacing `@` with `%40` if needed) to connect to the cloud.
3. **Creates a Route:** Tells the server to send a "The Brain is Working" message when someone visits the home page.

### 5. Running the Server

* **Command:** `node index.js`
* **Success Indicator:** Seeing the message **"Database Connected! ✅"** in the terminal.
